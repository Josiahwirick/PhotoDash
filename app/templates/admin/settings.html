Webhook

Add people and calendar entries without the admin UI via POST /api/webhook (used by the Discord bot, Shortcuts, or curl). Discord bot tokens live in /etc/photodash-discord.env, not here.

Example phrases the webhook understands:

  • add person Estelle #7cb89a
  • chore tomorrow: take out trash for Estelle
  • appointment Friday dentist
  • reminder today pack lunch
curl -s -X POST http://127.0.0.1:8080/api/webhook \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"text":"chore tomorrow: take out trash for Estelle"}'
